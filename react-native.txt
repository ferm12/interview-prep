value={value[index]}

editable – If false, makes the input read-only.

Real DOM (Document Object Model)
The Real DOM is what browsers use to represent the structure of HTML pages.

Virtual DOM
It’s a lightweight, in-memory representation of the Real DOM (or UI tree in React Native).

Shadow DOM
The Shadow DOM is a browser feature, mainly used for Web Components.
It allows encapsulation of styles and DOM structure, so the inner DOM of a component is isolated.
Example: A <my-button> Web Component can have its own internal DOM and CSS that doesn’t leak out.
React Native doesn’t use Shadow DOM because it doesn’t run in a browser—it renders to native UI components.


1. ScrollView
ScrollView renders all child components at once—even the ones off-screen.
✅ Use ScrollView when:
The list is small (e.g., < 20 items)
You have static or simple content
You don’t need windowing/virtualization

2. FlatList
FlatList is optimized for large lists.
It renders only what’s visible on the screen using virtualization.
✅ Use FlatList when:
You have big datasets
You want lazy loading / infinite scroll
Better performance and memory usage is needed
